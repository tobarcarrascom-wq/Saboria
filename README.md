# CocinaClick

Una página web de recetas moderna, responsive e interactiva.

## Funcionalidades

- Búsqueda por nombre o ingrediente.
- Filtros por categoría e ingredientes disponibles.
- Favoritos persistentes en el navegador.
- Ficha de receta con ajuste dinámico de porciones.
- Despliegue automático en GitHub Pages mediante GitHub Actions.

## Uso local

Abre `index.html` en un navegador o sirve la carpeta con cualquier servidor estático.
