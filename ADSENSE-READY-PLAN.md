# Saboria — preparación AdSense y lanzamiento

Estado de esta versión local: preparación parcial. No contiene código publicitario real, pagos, cuenta AdSense, publisher ID ni `ads.txt`.

## Ubicaciones publicitarias futuras

Cuando exista una cuenta legítima y autorización explícita, se recomienda probar solo:

1. Un bloque entre la sección destacada y la biblioteca.
2. Un bloque al final de una página individual de receta.
3. Un bloque al final de contenidos editoriales.

No ubicar anuncios dentro del modo cocinar, junto a botones, dentro del selector de ingredientes, cerca de favoritos, junto a controles de porciones o junto al Chef Saboria IA. Los espacios deben identificarse como publicidad y nunca parecer una receta o un control de navegación.

## Search Console

El propietario deberá:

1. Crear o usar su propia cuenta de Google.
2. Añadir `https://tobarcarrascom-wq.github.io/Saboria/` como propiedad.
3. Verificar la propiedad con el método que Google ofrezca para esa URL.
4. Enviar `https://tobarcarrascom-wq.github.io/Saboria/sitemap.xml`.
5. Inspeccionar algunas URLs de recetas y solicitar indexación cuando proceda.

No se conectó ninguna cuenta desde este proyecto.

## Analítica gratuita pendiente

No se activó analítica externa porque requiere una decisión de privacidad y consentimiento. Una opción posterior es una herramienta de medición respetuosa con la privacidad, configurada sin datos personales y documentada en la política. La alternativa mínima sin terceros es usar Search Console para consultas, impresiones, clics y páginas indexadas.

## AdSense: pasos cuando corresponda

1. El titular adulto debe crear su propia cuenta y completar identidad y pagos directamente con Google.
2. Añadir el sitio en AdSense y verificar la propiedad usando el código/meta que genere Google.
3. Esperar el estado `Ready` antes de servir anuncios.
4. Crear `ads.txt` solo con el publisher ID real entregado por Google.
5. Actualizar privacidad y consentimiento antes de cargar tecnologías publicitarias.
6. Solicitar revisión y esperar la decisión de Google.

GitHub Pages puede servir los archivos estáticos, pero GitHub advierte que Pages no está destinado principalmente a negocios comerciales, transacciones o SaaS. Si Saboria pasa a ser principalmente una plataforma comercial, habrá que evaluar alojamiento compatible sin asumir que será gratuito.
