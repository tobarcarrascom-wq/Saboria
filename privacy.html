Información clara

Política de privacidad

Saboria es un proyecto estático en etapa inicial. Actualmente no hay cuentas, pagos, publicidad, analítica externa ni envío de ingredientes a un servidor.

Datos guardados en tu navegador

El sitio puede usar almacenamiento local para favoritos, modo oscuro, progreso del modo cocinar y lista de compras. Puedes borrarlo desde la configuración del navegador.

Servicios externos

Las tipografías se cargan desde Google Fonts. Las ilustraciones de recetas y del encabezado se sirven desde archivos SVG originales del proyecto. Chef Saboria IA funciona con reglas locales y no usa una API generativa.

Publicidad futura

Si Saboria incorpora AdSense u otro proveedor, esta política se actualizará antes de activarlo para explicar cookies, proveedores, personalización, opciones de consentimiento y derechos aplicables. No se han instalado scripts publicitarios.

Contenido editorial

Las recetas se redactan para esta biblioteca y las cantidades marcadas como orientativas requieren validación humana. El contenido no sustituye asesoría médica, nutricional ni sanitaria.
